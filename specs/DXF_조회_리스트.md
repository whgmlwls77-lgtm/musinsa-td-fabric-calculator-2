## ✅ DXF 가져올 때 체크리스트

각 DXF 파일에 대해 다음 확인:

- [ ] 파일 확장자가 `.dxf` (또는 `.dxf` + `.pax` 같이)
- [ ] 부위명이 영문(FRONT BODY, SLEEVE 등)으로 들어있는지 — 자켓처럼 숫자만이면 검증 어려움
- [ ] 같은 품번 다른 버전이 있다면 가능하면 둘 다 (수정 이력 확인용)
- [ ] 풀 그레이딩(전 사이즈) vs 단일 사이즈 마스터 — 어느 쪽이든 OK
