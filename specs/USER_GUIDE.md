# 원단 요척 산출 시스템 — 사용 가이드

> **대상**: TD, MD, 생산담당자, 일반 사용자
> **목적**: 앱을 실무에서 정확하고 효율적으로 사용하는 방법 안내
> **URL**: https://musinsa-td-fabric-calc.streamlit.app/

---

## 1. 시작하기 전에

### 1.1. 시스템 요구사항
- **브라우저**: Chrome, Safari, Firefox, Edge (최신 버전 권장)
- **인터넷 연결**: 필수 (오프라인 사용 불가)
- **로그인**: 불필요 — URL만 알면 바로 사용

### 1.2. 준비할 것
- DXF 패턴 파일 (최대 50MB)
- 사용할 원단의 **폭(cm)** 정보
  - 주원단: 보통 140, 150, 152cm
  - 심지: 보통 110cm
  - 안감·배색·주머니감: 보통 110, 150cm

---

## 2. 기본 사용 흐름 (4단계)

```
① DXF 파일 업로드
    ↓
② 사이즈 선택    ← 풀 그레이딩 파일만 나타남
    ↓
③ 원단 폭 입력
    ↓
④ 요척 계산 + 다운로드
```

실제 작업 시간: **약 1-2분** (DXF 파일만 있으면).

---

## 3. 섹션별 상세 설명

### 📁 ① 파일 업로드

1. 점선 테두리 박스에 **DXF 파일 드래그** 또는 `Upload` 버튼 클릭
2. 업로드 완료되면 자동으로 분석 시작
3. 아래 정보가 표시됨:
   - ✅ **파일명**
   - ✅ **스타일명** (DXF 내부 메타에서 추출)
   - ✅ **샘플사이즈**
   - ✅ **피스 총 개수** (스케일박스 있으면 자동 제외 표시)
   - ✅ **재질 분류**: 주원단 N개 / 심지 N개 / 안감 N개 / 배색 N개

**⚠️ 이상 신호**: 모든 피스가 "미지정"으로 뜨면 → **DXF 재질 표기가 빠진 것**. 패턴사에게 [패턴 준비 가이드](PATTERN_PREP_GUIDE.md) 참고해서 재작업 요청하세요.

---

### 📏 ② 계산할 사이즈 선택 (풀 그레이딩 파일만)

**2개 이상 사이즈가 감지되면** 이 섹션이 나타납니다.

세 가지 모드 선택 가능:

- **단일 사이즈**: 하나만 계산 (기준 사이즈 자동 추천)
  - 상의 남자: L / 여자: S
  - 하의 남자: L 또는 32 / 여자: S 또는 26
- **복수 사이즈**: S와 L처럼 2개 이상 선택
- **전체 사이즈**: 모든 사이즈 자동 계산 후 표로

> 💡 **팁**: 가장 **많이 자주 쓰는 건 "단일 사이즈 — 샘플 사이즈"** (예: 상의 M, S, 하의 L 등). 공장 견적 견본 단계에서는 이걸로.

---

### 📐 ③ 원단 폭 입력

자동으로 감지된 재질별로 폭 입력 칸이 나타납니다.

| 재질 | 기본값 | 흔한 실제값 |
|------|-------|-----------|
| 주원단 | 150 cm | 140, 150, 152 cm |
| 심지 | 110 cm | 110 cm |
| 안감 | 150 cm | 110, 150 cm |
| 배색 | 150 cm | 150 cm |

**회사 발주서 원단 폭을 여기 그대로 입력**하세요.

#### ➕ 부속원단 추가
`부속원단 추가` 버튼을 누르면 **커스텀 원단**을 추가할 수 있어요:
- 예: 주머니감을 다른 원단으로 쓸 때
- 예: 콘트라스트 디자인 (앞판만 다른 재질)
- 이름 + 폭 입력 + 해당 피스 선택 → `추가`

---

### ⚙️ ④ 마커 효율

슬라이더 하나로 조정. 기본값 **80%**.

| 효율 | 상황 |
|------|------|
| 85~90% | 잘 짜인 마커 (숙련 패턴사, 간단한 아이템) |
| 78~82% | **일반적** (기본 권장 80%) |
| 70~75% | 복잡한 패턴, 다양한 사이즈, 그레이딩 많음 |
| ≤65% | 소량·특수 재단 |

> 💡 **실무 팁**: 첫 스타일 견적할 땐 80%로 시작 → 실제 마커 완성 후 그 효율값(%)으로 재계산하면 더 정확한 요척 산출.

---

### ▶️ 요척 계산하기

빨간색 **"요척 계산하기"** 버튼 클릭 → 즉시 결과 표시.

## 4. 결과 해석

### 4.1. 원단별 요척 카드

```
┌──────────────────────┐
│ 주원단                │
│ 0.92 yd              │
│ ↑ 0.84 m (폭 150cm)  │
└──────────────────────┘
```

- **큰 숫자** (0.92 yd): 미국식, 공장 발주서 기준
- **아래** (0.84 m): 미터법, 국내 원단 거래 기준
- **폭**: 입력한 원단 폭

### 4.2. 복수 사이즈 표

```
사이즈   주원단    심지     안감
XS      0.87 yd   0.05 yd   0.05 yd
S       0.92 yd   0.06 yd   0.06 yd
M       0.98 yd   0.06 yd   0.06 yd
L       1.04 yd   0.07 yd   0.07 yd
```

**사이즈별 약 3-4% 증가**하면 그레이딩이 정상이에요. 중간에 튀는 값이 있으면 그레이딩 룰 검토 필요.

### 4.3. 피스 프리뷰

- 각 피스가 독립 subplot으로 그리드 배치 (원본 레이아웃 무시)
- 각 피스: **제목**(P001 — SLV) + **크기**(46 × 56 cm) + **재질**
- 재질별 색상:
  - 🔘 주원단: 연한 회색
  - 🔷 심지: 연한 파랑
  - 🟡 안감: 연한 노랑
  - 🔺 배색: 연한 분홍
  - 🟢 주머니감: 연한 초록

## 6. 트러블슈팅

### ❌ 모든 피스가 "미지정"으로 나옴
**원인**: DXF에 Material 정보가 없거나 인식 못 하는 형식
**해결**: 패턴사에게 [패턴 준비 가이드 §6](PATTERN_PREP_GUIDE.md#6-재질-구분-가장-중요) 전달해서 재작업 요청

### ❌ 요척 값이 이상하게 작음
**가능한 원인**:
1. **수량이 1로만 표기됨** (소매·커프스 등은 2 필요) → 패턴사에 Quantity 확인
2. **완성선을 잡음** (시접 제외) → 재단선 아웃라인 확인
3. **파일이 일부 피스만 있음** (예: 안감 전용 파일)

### ❌ 풀 그레이딩 파일인데 사이즈 선택이 안 보임
**원인**: Size 메타가 없거나 인식 못 함
**해결**: 블록 내부 TEXT에 `Size: XS`, `Size: S` 등 명시되어 있는지 확인

### ❌ PDF 한글이 깨짐
현재는 이슈 없음 (Noto CJK 자동 설치됨). 만약 발생하면 담당자에게 제보 부탁드려요.

### ❌ 업로드가 실패함
- 파일 크기 **50MB 초과** → 파일 간소화 필요
- DXF 버전이 너무 오래됨 → AutoCAD 2013 이상으로 재저장

## 7. 자주 묻는 질문 (FAQ)

**Q1. 내 DXF 파일이 서버에 저장되나요?**
A. 아니요. 업로드된 파일은 **메모리에만 있다가 세션 종료 시 사라집니다**. 영구 저장 안 됨.

**Q2. 누구나 URL로 접속 가능한가요?**
A. 네. 공개 URL이라 링크만 알면 누구나 사용 가능. 보안 필요하면 담당자에게 비밀번호 보호 요청.

**Q3. 왜 사이즈별로 요척이 다른가요?**
A. 사이즈가 커지면 피스 면적도 커지니까요. 일반적으로 한 사이즈업당 3~4% 증가가 정상.

**Q4. 마커 효율 80%가 맞나요?**
A. 초기 견적 기본값이에요. **실제 마커 완성 후 그 효율값으로 재계산**하면 더 정확함.

**Q5. 부속원단 추가하면 뭐가 달라지나요?**
A. 기본 분류(주원단/심지/안감 등)와 **다른 원단 폭**으로 계산할 수 있어요. 콘트라스트 디자인, 특수 포켓 등에 사용.

**Q6. 앱이 느리게 열려요.**
A. **48시간 접속 없으면 Sleep**됩니다. 첫 접속 시 20-30초 걸릴 수 있어요 (깨어나는 시간).

**Q7. 모바일에서도 되나요?**
A. 작동하지만 **PC/태블릿 권장**. 화면 좁으면 테이블이 밀려 보일 수 있음.

## 8. 제한사항 / 알려진 이슈

- ⚠️ **1GB RAM 제한** (무료 플랜): 아주 큰 DXF (100MB+) 는 어려울 수 있음
- ⚠️ **48시간 미사용 시 앱 Sleep**: 다음 접속에 20-30초 소요
- ⚠️ **원단 단가 × 요척 = 원가 계산**은 아직 미지원 (V4에서 추가 예정)
- ⚠️ **앞넘김·뒷목깊이 같은 패턴 측정치 추출**은 별도 기능 (추후 개발)
