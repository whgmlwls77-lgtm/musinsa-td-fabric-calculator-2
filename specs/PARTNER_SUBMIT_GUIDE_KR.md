# 원단 요척 산출 시스템 — 협력사 DXF 제출 가이드 (한글)

> **대상**: 패턴 제출 협력사
> **목적**: DXF 파일이 요척 산출 시스템에 정확히 인식되도록 필수 규칙 명시
> **버전**: v1.3 (2026-07-14)

---

## §1. 왜 이 가이드가 필요한가

무신사 스탠다드의 AI 자동 요척 산출 프로그램은 협력사가 제출한 DXF 파일로
자동 요척을 산출합니다. DXF 표기가 규칙에 맞지 않으면 시스템이 조각 수량,
재질, 결방향을 잘못 인식해 요척 오차가 최대 40% 이상 발생할 수 있습니다.

아래 규칙을 지키시면 정확한 요척이 나옵니다.

> **PP-그레이딩 패턴 제출 시 시접이 포함된 패턴으로 제출해야 합니다.**

---

## §2. 필수 메타 정보 (조각마다 4개)

각 조각(블록) 안에 아래 4개 텍스트를 **반드시** 포함해야 합니다.
텍스트는 조각 안 어디에 놓아도 됩니다.

| 항목 | 형식 | 예시 | 비고 |
|---|---|---|---|
| **MATERIAL** | `MATERIAL: [재질]` | `MATERIAL: SELF` | §4 재질 5종 중 하나 (**국제 표준 영문**) |
| **QUANTITY** | `QUANTITY: [수량]` | `QUANTITY: 2` | 1벌당 실제 필요 수량 |
| **PAIRED** | `PAIRED: DOUBLE` | 좌우 대칭이면 필수 | 대칭 아니면 생략 |
| **SIZE** | `SIZE: [사이즈]` | `SIZE: L` | M / L / 32 등 |

> **주의**: 항목이 빠지면 시스템은 추측하지 않고 위반으로 처리합니다.
> 특히 `MATERIAL` 누락 시 요척이 잘못 산출됩니다.

---

## §3. 결방향 (식서) 표시

**모든 조각에 결방향(식서) 표시 필수.** 세로 / 가로 / 바이어스 중 하나.

---

## §4. 재질 표준 (5종만 허용)

`MATERIAL` 값은 아래 5가지 **국제 표준 영문** 중 하나여야 합니다.
그 외는 위반으로 처리됩니다.

| 재질 코드 | 한국어 | 설명 |
|---|---|---|
| **`SELF`** | 주원단 · 겉감 | 옷 본체 원단 |
| **`LINING`** | 안감 | 안감 원단 |
| **`POCKETING`** | 주머니감 | 주머니 안감 |
| **`CONTRAST`** | 배색 | 다른 색·소재로 배색 처리 |
| **`NON`** | 마카 제외 | 스케일 박스, 참고 조각 등 |

---

## §5. 단위 스케일 박스 (파일당 1개)

시스템이 DXF 좌표 단위(mm/cm/inch)를 자동 보정하기 위해
**50cm × 50cm 정사각형 박스**를 파일에 반드시 1개 추가합니다.

| 항목 | 값 |
|---|---|
| **블록 이름** | **`SCALE_BOX`** (표준 필수 · 대문자) |
| 크기 | 50cm × 50cm (정확히) |
| MATERIAL | `NON` |
| 위치 | 다른 조각과 겹치지 않는 곳 |

스케일 박스가 없거나 이름이 표준과 다르면 (예: `50x50`, `SIZE_BOX`) 좌표 단위 자동 보정 실패로 조각 면적이 최대 84% 왜곡될 수 있습니다.

---

## §6. 텍스트 표기 규정 (영문/숫자만 사용)

DXF 파일 내 **모든 텍스트**는 **영문 알파벳 및 숫자만 사용**해야 합니다.

| 대상 | 예시 |
|---|---|
| MATERIAL / QUANTITY / PAIRED / SIZE 값 | `SELF` / `2` / `DOUBLE` / `L` |
| 파일명 | `MMDPC513.dxf` |
| 조각 주석 (선택 사항) | `FRONT_BODY`, `SLEEVE` 등 영문 |

**한글/중국어/일본어 등 비ASCII 문자는 파일 인코딩 문제(CP949/EUC-KR 등)로 시스템이 텍스트를 잘못 읽을 수 있습니다.**

---

## §7. 기준 사이즈 라벨 통일 (PP ↔ 메인)

**PP 패턴과 메인 그레이딩 패턴은 기준 사이즈 라벨을 동일하게 표기해야 합니다.**

- PP 패턴의 기준 사이즈와 메인 패턴의 대응 사이즈가 **같은 `SIZE:` 값**을 사용해야 시스템이 자동 매칭합니다.
- 여성 라인 기준 사이즈 = `S` → PP도 `SIZE: S`, 메인도 `SIZE: S`
- 남성 라인 기준 사이즈 = `L` → PP도 `SIZE: L`, 메인도 `SIZE: L`
- 라벨이 다르면 (예: PP `Medium` / 메인 `M`) 시스템이 매칭 실패 → 축율 검증 불가

> 라벨 표기 예: `S`, `M`, `L`, `XL`, `26`, `32` 등. PP와 메인이 같은 라벨이면 시스템이 자동 대조.

---

## §8. 축율 (Shrinkage) 별도 인폼

**기준 사이즈에서 축율분을 반영한 경우, 축율 몇 %인지 별도 인폼(문서/이메일)에 기재하여 제출합니다.**

| 항목 | 형식 예시 |
|---|---|
| 원단명 | (예: 100% Cotton Twill 200gsm) |
| 세로 축율 (%) | (예: 3%) |
| 가로 축율 (%) | (예: 2%) |
| 축율 반영 여부 | 반영 / 미반영 |

축율 반영 여부와 %를 명시하지 않으면 시스템이 PP 패턴 대비 메인 패턴 면적 차이를 정확히 검증할 수 없습니다.

---

## §9. 파일 제출

- **DXF 파일** + **rul 파일** 함께 제출
- 파일명은 **영문/숫자만** (한글/특수문자 X)
- 축율 반영 시 **축율 인폼**(§8) 첨부

---

## §10. 제출 전 체크리스트

파일을 보내기 전 아래 항목 모두 확인:

- [ ] **시접이 포함된 PP-그레이딩 패턴으로 제출** (net 패턴 X)
- [ ] 조각마다 `MATERIAL: [SELF/LINING/POCKETING/CONTRAST/NON]` 텍스트 있음
- [ ] 조각마다 `QUANTITY: [실제 수량]` 텍스트 있음
- [ ] 좌우 대칭 조각에 `PAIRED: DOUBLE` 텍스트 있음
- [ ] 조각마다 `SIZE: [사이즈 라벨]` 텍스트 있음
- [ ] 조각마다 결방향(식서) 표시 있음 (세로 / 가로 / 바이어스 중 하나)
- [ ] 파일에 50cm × 50cm 스케일 박스 1개 (MATERIAL: NON)
- [ ] **PP 패턴과 메인 패턴의 기준 사이즈 라벨 통일** (§7 — 자동 대조 위해 필수)
- [ ] **DXF 내 모든 텍스트가 영문/숫자만 사용** (한글/중국어/일본어 X)
- [ ] 파일명 영문/숫자
- [ ] 축율 반영 시 축율 인폼(§8) 첨부
- [ ] DXF 파일과 rul 파일 함께 제출
