## 1. 가설 A — 단위 보정 시 면적 누락 (1D vs 2D) — ✅ raw 검증

### 1.1. 가설 정의 (사장님 본질)
50cm × 50cm 박스 자동 보정 시 좌표 (1D) 는 ratio 적용되지만 **면적 (2D) 은 ratio² 누락 가능성**.
누락 시 박스 area_cm2 = 19.685² ≈ 387.5 sq cm (정상값 2500 의 15.5%).
효율 계산 = 면적 합 / 마카 면적 → 면적 1/6.45 → 효율 1/6.45 → -7p 갭 가능.

### 1.2. raw 측정 (`MMAPS003-test.dxf` 보정 후)

| piece | width × height | area_cm2 | 기대 (정상) | 비정상 (1D만) |
|---|---|---|---|---|
| 50X50 박스 | 49.9999 × 49.9999 cm | **2499.99** | 2500.00 (50²) | 387.49 (19.685²) |

**판정**: ✅ **가설 A ❌ 부정** — area_cm2 정확히 50² ≈ 2500 적용됨.

### 1.3. 코드 검증

`dxf_diagnosis.apply_unit_correction_50cm_box()` (line 697-704):

```python
r2 = correction * correction              # ← ratio² 별도 계산
for p in pieces:
    if p.get("width_cm") is not None:
        p["width_cm"] = float(p["width_cm"]) * correction       # 1D
    if p.get("height_cm") is not None:
        p["height_cm"] = float(p["height_cm"]) * correction     # 1D
    if p.get("area_cm2") is not None:
        p["area_cm2"] = float(p["area_cm2"]) * r2               # 2D ✅
    if p.get("bbox_cm") is not None:
        p["bbox_cm"] = tuple(float(v) * correction for v in ...)  # 1D
    if p.get("coords_cm") is not None:
        p["coords_cm"] = [(x * correction, y * correction) ...]   # 1D
```

→ **면적 보정 정상**. 좌표 (1D) ratio + 면적 (2D) ratio² 별도 적용.

### 1.4. 결론
