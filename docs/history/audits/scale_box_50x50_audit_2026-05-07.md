# 50x50 비율 박스 audit — DXF 단위 미스매치 적발 (2026-05-07)

> 사장님 종합 피드백 #35 작업 D — 50x50 비율 박스로 DXF 스케일 절대 기준 검증.
> §1.5.1: raw 데이터 우선, 사장님 본질 반영, 추측 X.

## 1. raw 측정 결과

### 1.1. 50x50 박스 piece raw

| 항목 | 값 |
|---|---|
| Block name | `50X50_Medium` |
| piece_name | `50X50` |
| material_raw | `NON` |
| material_inferred | `마카제외` ✅ |
| 외곽선 | POLYLINE (4 vertex) |
| **raw bbox (DXF units)** | **19.6850 × 19.6850** |
| 측정 bbox (cm 가정) | 19.685 × 19.685 cm |
| 사장님 의도 | **50 × 50 cm** |

### 1.2. 단위 가설 검증

| 가설 | 변환 | 결과 | 사장님 의도 일치? |
|---|---|---|---|
| DXF=cm  (×1) | 19.6850 ÷ 1 | 19.685 cm | ❌ |
| DXF=mm  (÷10) | 19.6850 ÷ 10 | 1.969 cm | ❌ |
| **DXF=inch (×2.54)** | **19.6850 × 2.54** | **49.9999 cm** | **✅** |

**결론**: **DXF 좌표가 inch 단위**. 우리 시스템이 cm 로 잘못 가정 → 모든 piece 가 1/2.54 작음.

### 1.3. detect_unit_scale_to_cm 적발

```
$INSUNITS: unset
$LUNITS:   unset
$MEASUREMENT: unset

detect_unit_scale_to_cm: scale=1.0 (cm/unit), label='cm (좌표 기반 추정)'
```

DXF 헤더가 모두 unset (사장님 명시 — 신뢰 금지). `detect_unit_scale_to_cm` 가
좌표 기반 추정으로 cm 결정 → **inch DXF 인식 실패**.
